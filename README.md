# Akash's JARVIS (Android)
1. Android Studio (ফ্রি) install করুন → Open → এই JarvisAI ফোল্ডার সিলেক্ট করুন → Sync শেষ হওয়ার অপেক্ষা।
2. ফোনে USB debugging চালু করে Run চাপুন (অথবা Build > Build APK)।
3. অ্যাপে ⚙ → Gemini API key দিন (aistudio.google.com, ফ্রি) → Save।
4. ⚙ থেকে Accessibility আর Notification access চালু করুন।
   Android 13+ এ গ্রে হয়ে থাকলে: Settings > Apps > JARVIS > ⋮ > Allow restricted settings.
5. 🎤 চেপে বলুন: "WhatsApp খোলো, রুবেল দাসকে Hi পাঠাও", "scroll করো", "আজকের নোটিফিকেশন পড়ো"।
